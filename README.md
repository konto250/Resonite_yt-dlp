# Resonite で Youtube 動画が上手く再生できない場合の対処法を考えてみた

今のところ問題なく再生できているなら、なにも変えることはないので、以下は読まなくていいです。

「なんかガチャガチャやってたら直った」にすこしでも根拠らしきものを与えようとおもい、ここ数日ログとにらめっこした結果です。

n=1 なので、その点だけは注意してください。

---

## 対処法

Resonite の「設定 → ビデオストリーミングサービス → ブラウザの Cookie を使用」を切り替えてみる。

常用していないブラウザで YouTube にログインし、「ブラウザの Cookie を使用」をそのブラウザに切り替える。

- Firefox を常用していないなら Firefox が扱いやすい（Resonite 使用中も開いたまま使える）
- Chromium 系（Chrome/Edge/Brave/Vivaldi）を使う場合は、Resonite 使用中はそのブラウザを完全に閉じておく必要がある

> **なぜ Firefox が扱いやすいか**
>
> Chromium 系（Chrome/Edge/Brave/Vivaldi）は、起動中に Cookie のデータベースファイルをロックする。この状態だと Resonite が Cookie を読めず、動画が一切再生できなくなる。
> Firefox はロックしないので、開いたままでも問題ない。
> これは、Firefox の方が yt-dlp のような外部ツールから扱いやすいということである。

Youtube にログインするアカウントは捨て垢がよいかも？（過去に作って普段使っていない Google アカウントとか、ソシャゲのデーター連携のために1個ぐらいそういう垢あるでしょ？）

一度うまくいっても、そのブラウザでログアウトしたり Cookie を消すと元に戻る。

これで Youtube 動画が見えるようになった場合、おそらくライブが見られないとおもうので、ライブみるときだけ「ブラウザの Cookie を使用」を「NONE」にする。

これでうまくいくかは yt-dlp、Resonite のアップデートによって変わる。
